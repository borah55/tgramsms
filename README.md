# DogeMine — Dogecoin Cloud Mining Platform

A complete Dogecoin cloud-mining simulation platform built with **PHP, MySQL,
Bootstrap 5, and Font Awesome 6**. Designed to deploy on **cPanel shared
hosting** with zero compilation steps.

## Features

- **Wallet + 4-digit PIN** authentication, no email required
- **100 GH/s lifetime free** mining bonus on signup (0.2 DOGE / day)
- **Mining plans** with mining speed, price, daily reward, duration, bonus %
- **CoinPayments** deposit gateway with HMAC-verified IPN
- **Withdrawals** with admin approval, fee, and 24h limit
- **15% referral commission** with multi-level statistics
- **Animated dashboard** — per-second balance counter, mining progress bar,
  notifications dropdown
- **Full admin panel** — users, plans, deposits, withdrawals, tickets,
  announcements, security logs, CSV reports, CoinPayments and site settings
- **Security** — CSRF tokens, prepared statements, XSS filtering, IP
  rate-limiting, security event log, password (PIN) hashing with bcrypt
- **Theme** — Dogecoin yellow / black / white, dark + light mode toggle
- **Fake live earning notifications** that can be enabled in settings
- **Maintenance mode**, **Google Analytics**, terms / privacy / FAQ pages

## Installation (cPanel)

### 1. Upload

- Compress the `dogemine` folder into a ZIP.
- Open **cPanel → File Manager** and upload the ZIP into `public_html` (or any
  subfolder, e.g. `public_html/dogemine`).
- Right-click → **Extract**.

### 2. Create the database

- Go to **cPanel → MySQL Databases**.
- Create a new database (e.g. `myuser_dogemine`).
- Create a database user and **add it to the database with ALL PRIVILEGES**.

### 3. Run the installer

- Visit `https://your-domain.com/install.php`.
- The installer walks you through 4 steps:
  1. Server requirements check.
  2. Database credentials + site URL → schema is imported automatically.
  3. Set the admin password.
  4. Done.

### 4. Delete the installer

For security, **delete `install.php` from your server** after step 4.

```bash
rm install.php
```

### 5. Configure CoinPayments

- Sign in at https://www.coinpayments.net.
- Go to **Account → API Keys** and create a key with **Public + Private**
  permissions.
- Go to **Account → Account Settings → IPN/Merchant Settings**, enable IPN
  and set the **IPN Secret**.
- In the DogeMine admin panel open **CoinPayments**:
  - Merchant ID
  - Public Key
  - Private Key
  - IPN Secret
- In CoinPayments → **Coin Acceptance Settings → DOGE → IPN URL**, set:

  ```
  https://your-domain.com/ipn/coinpayments.php
  ```

## How Mining Is Calculated

Every active plan has a `daily_reward` (DOGE / day). A user's per-second rate
is `sum(daily_reward) / 86400`. Earnings are credited:

1. On every dashboard load.
2. Every 30 seconds via `/ajax/mining.php`.
3. Whenever a withdrawal/plan-purchase action is taken.

This means counters always converge to the **server-side truth** and cannot be
manipulated client-side.

## Security Notes

- All POST forms are **CSRF-protected** (`includes/security.php`).
- All queries use **PDO prepared statements**.
- Output is escaped with `e()` (`htmlspecialchars` with `ENT_QUOTES`).
- PINs are hashed with **bcrypt**.
- The `/includes/` directory is locked behind its own `.htaccess`.
- IP-based **lockout** after 5 failed login attempts in 15 minutes.
- IPN payloads are verified with **HMAC-SHA512** against `cp_ipn_secret`.

## Configuration File

`includes/config.php` is generated by the installer and contains:

```php
DB_HOST, DB_NAME, DB_USER, DB_PASS, DB_CHARSET
SITE_URL                // No trailing slash
TIMEZONE                // e.g. UTC
APP_KEY                 // Random 32+ char string
SESSION_NAME            // Cookie name for sessions
REMEMBER_COOKIE         // Cookie name for "remember me"
CSRF_TOKEN_NAME         // POST field name for CSRF
MAX_LOGIN_ATTEMPTS      // Default 5
LOCKOUT_MINUTES         // Default 15
DEBUG_MODE              // true/false
```

## Updating

1. Back up `includes/config.php`.
2. Replace all files except `includes/config.php` and `includes/.installed`.
3. If `database.sql` changes, run any migration manually in phpMyAdmin.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| `install.php` keeps loading itself | Make sure `includes/` is writable by PHP. |
| `Database connection failed` | Verify cPanel DB user has `ALL PRIVILEGES`. |
| AJAX endpoints return 401 on dashboard | Cookies/sessions blocked by hosting. Check `session.save_path` is writable. |
| CoinPayments IPN returns `Invalid HMAC` | Make sure the IPN Secret in admin matches CoinPayments and that you're using `https://`. |
| Dashboard counter frozen | Open browser console for fetch errors — usually wrong `SITE_URL` in config. |
